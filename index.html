Proyectos Destacados

Proyecto 1: Sistema FootLocker

Sistema de gestión para una tienda de tenis deportivos y casuales que permite administrar productos, marcas, precios e imágenes mediante operaciones CRUD.

Tecnologías utilizadas: Java, Windows Forms, MySQL, ADO.NET, Visual Studio 2022.

Mi rol: Desarrollo de la base de datos, conexión con la aplicación y creación de formularios.

Resultados: Se logró crear una aplicación funcional conectada a una base de datos real.

Proyecto 2: PadelPro Design

PadelPro Design es una tienda en línea enfocada en la personalización de palas de pádel. El objetivo del proyecto fue diseñar una plataforma donde los usuarios puedan elegir diseños personalizados para sus palas deportivas.

Tecnologías utilizadas: HTML, diseño web y herramientas de prototipado.

Mi rol: Diseño de la interfaz web y estructura del catálogo de productos.

Resultados: Se desarrolló un prototipo funcional que muestra productos, diseños y opciones de personalización.
